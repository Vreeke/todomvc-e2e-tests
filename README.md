# TodoMVC — E2E та Screenshot тестування (Лабораторна робота № 6)

Проєкт містить веб-додаток управління списком завдань TodoMVC (`public/index.html`, `public/about.html`) та набір автоматизованих E2E і Screenshot тестів на базі **Playwright** для десктопних браузерів (Chromium, Firefox) та мобільної версії браузера (Mobile Chrome).

## Запуск
```bash
npm install
npx playwright install
npx playwright test --update-snapshots
npm test
```
